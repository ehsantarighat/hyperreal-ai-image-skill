# Model Consistency Reference

Use this reference to extract and preserve a model’s visual identity across one or many images.

## Identity extraction checklist

Describe only visible, relevant, non-sensitive features:
- face shape
- jawline and cheek structure
- eye shape and relative spacing
- eyebrow shape
- nose and lip proportions
- hairstyle, length, texture, parting
- hair color
- visible skin tone and texture
- age impression only as a broad visual impression
- distinctive facial details only if clearly visible
- signature expression or natural resting expression

## Reusable model consistency block

> Use the exact same person from the provided model reference image. Preserve facial identity across outputs, including face shape, age impression, eye structure, eyebrow shape, nose and lip proportions, hair appearance, skin tone, and overall likeness. Do not stylize, beautify, de-age, age-up, or alter the model’s identity. The result must look like the same real person photographed in a new setting.
