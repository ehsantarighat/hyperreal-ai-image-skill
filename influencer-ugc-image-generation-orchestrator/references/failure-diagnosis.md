# Failure Diagnosis Reference

Use this file when a generated result is disappointing.

## Diagnose in this order

1. model mismatch
2. product distortion
3. hand/contact failure
4. artificial skin / CGI feel
5. camera mismatch
6. lighting mismatch

## Repair principles
- strengthen model identity preservation
- reinforce exact product geometry
- correct hand anatomy and product contact
- restore skin texture and realistic light
